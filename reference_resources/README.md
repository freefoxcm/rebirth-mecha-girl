## 每人三类设计图

1. **人形三视图**：正面、90°侧面、180°背面，展示收纳后的机翼、发动机、关节与装甲关系。
2. **完整战机三视图**：正面、侧面、俯视，展示飞行构型及关键部件。
3. **六阶段变形设计**：01 人形锁定 → 02 翼板解锁 → 03 躯体前倾收纳 → 04 机身成形 → 05 尾翼/座舱/喷口锁定 → 06 完整战机。

## 共通设计原则

- 她们本身就是机械生命，不是穿着机甲的普通人，也不是飞机驾驶员。
- 成年外观 23—29 岁，五官自然、服装完整、表达克制，避免兽化、尖刺和无意义裸露。
- 核心机体零件可追踪：单发/双发数量、人形背部喷口、收折翼板和战机状态保持对应。
- 国家或地域差异只作为美术语言与航空布局参考；**所有角色和机体均为原创虚构设定**，不采用真实国旗或现役军队身份。
- 图片为概念美术，局部尺寸、机械折叠空间和六步运动链需要在正式 3D 建模前复核；图中的自动生成技术数字并非真实工程参数。
