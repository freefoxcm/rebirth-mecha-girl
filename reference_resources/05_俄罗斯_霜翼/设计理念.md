# 霜翼 SNEGA-57

**系列**：俄式重型航空工程与寒地极简机械美学  
**外观年龄**：29 岁  
**类型**：双发重型超机动机械生命  
**任务**：高机动截击、纵深突防、复杂空域近距格斗、重载机动护航  
**战机造型参考**：苏-57 的宽翼身融合布局、双发与推力矢量喷口；原创虚构机体。

## 设计理念

霜翼的力量感来自结构重量与控制力，而非狂暴或野性。角色体态挺拔稳定，霜白装甲覆盖经过精简的深钢蓝骨架，冷青指示灯点到为止。成熟女性面容、灰金色低辫、钢蓝色眼睛，目光坚定但不凶狠。肩、髋、小腿的翼面收纳比其他四人更大，表明她在人形状态下仍承受重型战机的机体质量。

## 性格与游戏定位

寡言、可靠、守纪律，承担高风险任务时冷静得近乎固执。战斗定位是强突破与截击：瞬时加速与大攻角机动优秀，可为队友挡住高速威胁，但能耗和机体惯性较大。

## 人形固定识别点

- 灰金色粗低辫、钢蓝眼睛、成熟冷静的俄罗斯成年女性气质。
- 霜白主体、深钢蓝装甲分区、冷青设备灯；肩髋部更宽但轮廓流畅。
- 后腰**两具间隔较大的矢量喷口**，其运动环和连杆在背面清晰可见。
- 宽阔主翼从肩背与腿外侧多层折叠，背部双垂尾收进宽型骨架。

## 完整战机

原创重型双发隐身截击机：大面积翼身融合、两套间距明确的矢量喷口、倾斜双垂尾、宽阔主翼与饱满机身。冷色纹理强调寒地科技感，但不使用真实军队标识。

## 六阶段变形逻辑

1. **人形锁定**：宽型翼板紧贴肩背与外腿，双矢量喷口分列后腰。
2. **主翼解锁**：肩部翼根外翻，腿侧翼面释放，喷口矢量机构进入空转校准。
3. **上体重构**：头部进入前机身防护区，手臂与胸甲组成延长机鼻。
4. **宽体形成**：骨盆与双腿伸缩形成后机身，主翼拼接完成翼身融合外形。
5. **尾部锁定**：双垂尾抬起，两套喷口展开为完整推力矢量组件。
6. **战机完成**：机身蒙皮闭合，双发切换飞行模式，进入重型超机动构型。

## 制作注意

优先解决主翼展开时的质心变化、双发动机间距及推力矢量活动余量。模型表现应保持“沉稳的大型飞机”，不演变成背负尖刺和巨剑的传统机甲。
