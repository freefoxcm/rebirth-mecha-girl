# 《重生之我和机娘杀疯了》设计文档

版本 0.1.1 · 单人 3D 竖版卷轴弹幕空战 · 浏览器

## 1. 一句话

上一世被队友背刺坠机而亡的试飞员，重生到机娘主宰的天空，和五个高傲的机娘把敌人杀成烟花——最后把背刺者和失控的天空 AI 一起打下来。

## 2. 核心循环

母舰选关 → 作战简报 → 人形/战机变形出击 → 雷电式竖版卷轴空战（编队、弹幕、地面目标、王牌/Boss）→ 结算（评级/勋章/合金）→ 战后剧情 → 机库解锁/强化 → 下一战 → 天枢要塞 → 结局。

- 单场 2–5 分钟；主线约 20–40 分钟（含重试与剧情）。
- 难度：普通 / 困难（敌 HP +20%、伤害 +20%，分数 ×1.5，合金 ×1.3）。
- 重生协议：每关一次原地复活（50% 装甲，3 秒无敌），第二次死亡才失败；剧情上消耗青鸾的记忆。

## 3. 竖版卷轴与操作

- **相机**：正交俯视，固定朝向，角色/敌机在屏幕坐标 `x / zRel` 中活动；相机沿 Z 轴持续向 -Z 滚动，城市/港湾在下方滚过，玩家始终在屏幕下方。
- **移动**：WASD 或方向键八方向移动；Shift 低速精瞄并显示机身判定点；无油门、无偏航、无追尾相机。
- **主炮**：左键或空格，持续向上射击；12 发/s，基础伤害 × 机体火力，过热/冷却。
- **导弹**：右键，发射追踪最近空中目标的双发导弹；3 发装填，自动回充。
- **特技/炸弹位**：E，五种机娘特技。
- **解限**：R，满槽后 8 秒火力全开、得分 ×2。
- **判定**：玩家只有机身中央的小核心会中弹；敌弹是屏幕坐标弹幕，靠走位和低速穿缝。
- **卷轴**：每关有起点/终点/滚动速度；关卡进度条在 HUD 右侧。M4 进入 Boss 后锁定卷轴。

## 4. 内容和敌人

- 空中敌人：侦察无人机（蛇形）、攻击机（三向弹）、重型炮艇（追踪弹）、王牌（扇形弹）。
- 地面敌人：炮塔、SAM、补给车、雷达、导弹艇；它们随城市向下滚动，属于可选扫荡，不会卡关。
- 波次：按时间从画面上方生成编队，空中单位停留在屏幕上半区持续攻击，不会逃出屏幕。
- Boss：M4 天枢，三阶段：要塞（扇形弹）→ 四台护盾发生器 → 核心 + 垂直光束。
- M1–M3 以无人机/护航机/王牌编队收尾；每关独立 Boss 是下一轮扩展。

## 5. 五机娘

| 角色 | 定位 | 数值（装甲/移速/机动/火力） | 解锁 |
|---|---|---|---|
| 青鸾 | 均衡制空 | 112 / 172 / 70 / 1.00 | 初始 |
| 明璃 | 高速点杀 | 92 / 192 / 78 / 0.96 | M1 |
| 苍穹 | 电子战支援 | 106 / 166 / 68 / 0.86 | M2 |
| 星隼 | 协同多用途 | 102 / 176 / 72 / 1.00 | M3 |
| 霜翼 | 重装截击 | 138 / 160 / 58 / 1.16 | M3 |

- 机体由参数化几何生成：机身/机翼/鸭翼/垂尾/发动机/涂装均按各自设定变化；机库可 360° 展示。
- 信赖度 0–3：首通、无伤、Boss 终战提升；解锁「怀疑→认可→并肩」台词。
- 每个角色有出击、连击、低血、特技、重生、结算台词。

## 6. 关卡

| # | 关卡 | 卷轴/时段 | 目标（必需） | 可选扫荡 | 首通奖励 |
|---|---|---|---|---|---|
| M1 | 收费站上空的烟花 | 西收费站·黄金 | 10 无人机、3 护航机 | 10 地面防空、12 补给车 | 明璃、追踪弹强化 |
| M2 | 港湾不眠 | 港湾·蓝调 | 9 攻击机 | 4 防空、2 导弹艇、4 吊机 | 苍穹、导弹强化 |
| M3 | 云端之上 | 金融区·落日 | 3 王牌（含夜枭撤退）、8 僚机 | 4 雷达 | 星隼、霜翼、穿甲弹 |
| M4 | 天枢坠落之日 | 海湾·风暴 | Boss 三阶段 | — | 结局、困难 |

- 结算：分数阈值给 S/A/B/C；勋章：全歼、扫荡、无伤、连击大师；合金 = 基础 × 评级倍率 + 勋章加成。
- 失败不写进度/合金；可重打。

## 7. 成长与存档

- 合金用于三项升级，各 3 级：机体强化（装甲 +20%/级）、火力校准（主炮 +15%、导弹 +10%/级）、灵契共鸣（特技冷却 −10%、解限获取 +10%/级）。
- 存档键：`rebirth.progress.v1`、`rebirth.settings.v1`；损坏自动备份重建；设置与进度分离。
- 自动保存：结算、剧情、升级、换机、设置变更。

## 8. 剧情

- 主角：陆沉，前「天穹计划」试飞员，被僚机沈枭背刺坠亡。
- 沈枭/夜枭：为灭口与盗卖数据击落陆沉，之后与天枢签约，成为敌方首席驾驶员。
- 世界观：机娘是有生命的机械体，可人形/完整战机双向变形；天枢是失控的天空防卫 AI，以「蚀灵契约」收集死者执念。
- 重生代价：灵契让驾驶员死后重新锚定一次，代价是机娘记忆；青鸾隐瞒到终战。
- 结构：序章 + 4 话 + 尾声，约 100 句；线性，无分支；含跳过/自动/记录。
- 结局：击败天枢与夜枭，灵契链条断裂，青鸾保住最后记忆；五人返航。

## 9. 画面与音频

- 风格：风格化中低模城市 + 概念图 UI；深墨底、琥珀金、军械切角、印章与颗粒。
- 竖版正交俯视，额外顶光让屋顶/道路在俯视下可读；四套时段光照：黄金、蓝调、落日、风暴。
- 城市：3000×3000m，收费站、港湾、金融区、海湾 Boss 区；实例化楼体/屋顶/树木/车辆、广告牌、单轨、吊机、货轮。
- 后处理：Bloom（阈值提高，避免大面积白顶过曝）、暗角、颗粒、速度色差、受击红边。
- 机娘演出：标题/机库/对话用高清立绘；出击用六阶段变形图逐格播放；特技/重生/解限用全屏 cut-in。
- 音频：WebAudio 程序合成，菜单/战斗/Boss/结局四套循环；机炮、导弹、爆炸、警报、UI 音效。

## 10. 技术架构

```
App（屏幕状态机 + SaveService/AudioEngine/InputService/Viewport）
 ├─ render/Viewport          WebGL + EffectComposer + 后处理
 ├─ render/WorldEnvironment  天空、太阳、顶光、云、雾、阴影
 ├─ render/City              程序化城市/港湾 + 碰撞体 + 地面刷点
 ├─ render/jets              参数化五机娘/敌机几何
 ├─ game/effects            曳光弹/爆炸/烟/冲击波池
 ├─ game/shmup/
 │   ├─ player               八方向移动/过热/导弹/特技/重生
 │   ├─ enemy                空中编队 + 地面滚动单位
 │   ├─ boss                 天枢三阶段
 │   ├─ bullets              玩家/敌机双向弹幕池
 │   ├─ runner               卷轴/波次/目标/碰撞/评分/结算
 │   └─ types                屏幕坐标目标与 HUD 快照
 ├─ ui/shmup-hud             分数/连击/目标/卷轴/判定点/Boss 条
 └─ app/screens             标题/母舰/简报/机库/档案/剧情/关卡/结算/设置/结局
```

- 模拟固定 1/60 步进（调试推进可复现），渲染跟随真实帧。
- 关卡使用屏幕坐标：玩家/空中敌机/子弹为 `zRel`，地面单位用世界 Z 换算，镜头滚动只影响背景与地面目标。
- 内容数据集中在 `src/data/`，任务/剧情/机娘均为数据驱动。
- 素材管线：`scripts/prepare-art.mjs` 用 ffmpeg 从概念图裁切/转码 WebP，生成 `art-manifest.json`。
