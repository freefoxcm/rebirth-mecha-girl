# 《重生之我和机娘杀疯了》设计文档

版本 0.2.0 · 单人 3D 竖版卷轴弹幕空战 · 浏览器

## 1. 一句话

上一世被队友背刺坠机而亡的试飞员，重生到机娘主宰的天空，和五个高傲的机娘把敌人杀成烟花——最后把背刺者和失控的天空 AI 一起打下来。

## 2. 核心循环

母舰选关 → 作战简报 → 人形/战机变形出击 → 雷电式竖版卷轴空战（编队、弹幕、地面目标、王牌/Boss）→ 结算（评级/勋章/合金）→ 战后剧情 → 机库解锁/强化 → 下一战 → 天枢要塞 → 结局。

- 单场 2–5 分钟；主线约 20–40 分钟（含重试与剧情）。
- 难度：普通 / 困难（敌 HP +20%、伤害 +20%，分数 ×1.5，合金 ×1.3）。
- 重生协议：每关一次原地复活（50% 装甲，3 秒无敌），第二次死亡才失败；剧情上消耗青鸾的记忆。

## 3. 竖版卷轴与操作

- **相机**：正交俯视，固定朝向，角色/敌机在屏幕坐标 `x / zRel` 中活动；相机沿 Z 轴持续向 -Z 滚动，城市/港湾在下方滚过，玩家始终在屏幕下方。
- **移动**：WASD 或方向键八方向移动；Shift 低速精瞄并显示机身判定点；无油门、无偏航、无追尾相机。
- **主炮**：左键或空格，持续向上射击；12 发/s，基础伤害 × 机体火力，过热/冷却。
- **导弹**：右键，发射追踪最近空中目标的双发导弹；3 发装填，自动回充。
- **特技/炸弹位**：E，五种机娘特技。
- **解限**：R，满槽后 8 秒火力全开、得分 ×2。
- **判定**：玩家只有机身中央的小核心会中弹；敌弹是屏幕坐标弹幕，靠走位和低速穿缝。
- **卷轴**：每关有起点/终点/滚动速度；关卡进度条在 HUD 右侧。关底 Boss 出现后锁定卷轴，战场停在对应地标。

## 4. 内容和敌人

- 空中敌人：侦察无人机（蛇形）、攻击机（三向弹）、重型炮艇（追踪弹）、王牌（扇形弹）。
- 地面敌人：炮塔、SAM、补给车、雷达、导弹艇；它们随城市向下滚动，属于可选扫荡，不会卡关。
- 波次：按时间从画面上方生成编队，空中单位停留在屏幕上半区持续攻击，不会逃出屏幕。
- 关底 Boss：M1 铁颚（重装炮艇）、M2 潮汐（导弹母舰）、M3 烛龙（空中堡垒）、M4 天枢（护盾发生器 + 核心）。
- M1–M3 的 Boss 在最后一批编队清空后进入；M4 开场进入；具体阶段/弹幕见 6.1。

## 7. 成长与存档

- 合金用于三项升级，各 3 级：机体强化（装甲 +20%/级）、火力校准（主炮 +15%、导弹 +10%/级）、灵契共鸣（特技冷却 −10%、解限获取 +10%/级）。
- 存档键：`rebirth.progress.v1`、`rebirth.settings.v1`；损坏自动备份重建；设置与进度分离。
- 自动保存：结算、剧情、升级、换机、设置变更。

## 8. 剧情

- 主角：陆沉，前「天穹计划」试飞员，被僚机沈枭背刺坠亡。
- 沈枭/夜枭：为灭口与盗卖数据击落陆沉，之后与天枢签约，成为敌方首席驾驶员。
- 世界观：机娘是有生命的机械体，可人形/完整战机双向变形；天枢是失控的天空防卫 AI，以「蚀灵契约」收集死者执念。
- 重生代价：灵契让驾驶员死后重新锚定一次，代价是机娘记忆；青鸾隐瞒到终战。
- 结构：序章 + 4 话 + 尾声，约 100 句；线性，无分支；含跳过/自动/记录。
- 结局：击败天枢与夜枭，灵契链条断裂，青鸾保住最后记忆；五人返航。

## 9. 画面与音频

- 风格：风格化中低模城市 + 概念图 UI；深墨底、琥珀金、军械切角、印章与颗粒。
- 竖版正交俯视，额外顶光让屋顶/道路在俯视下可读；四套时段光照：黄金、蓝调、落日、风暴。
- 城市：3000×3000m，收费站、港湾、金融区、海湾 Boss 区；实例化楼体/屋顶/树木/车辆、广告牌、单轨、吊机、货轮。
- 场景细节：交叉口斑马线；屋顶停机坪 H、天线、水箱、光伏板、退台冠部；港湾仓库/卷帘门/通风/系缆桩/码头灯；金融区空中连廊/单轨站台/广场花坛；收费站车道信号灯/护栏。
- 后处理：Bloom（阈值提高，避免大面积白顶过曝）、暗角、颗粒、速度色差、受击红边。
- 机娘演出：标题/机库/对话用高清立绘；出击用六阶段变形图逐格播放；特技/重生/解限用全屏 cut-in。
- 音频：WebAudio 程序合成，菜单/战斗/Boss/结局四套循环；机炮、导弹、爆炸、警报、UI 音效。

### 9.1 战机外形工程

- **Blender 管线**：`art/blender/lib/` 内的参数化 hard-surface 库按 `jet_specs.py` 中的数据生成五台机；每台包含 30–48 个机身站位、带折线 chine 的截面、单块折线机翼（7 个平面控制点）、鸭翼/LEVCON、外倾双垂尾/单垂尾、DSI/caret/belly 进气、单/双/矢量喷口、座舱内构、起落架和几何面板线。
- **源文件与导出**：`art/blender/build_jets.py` 保存可编辑 `art/blender/source/<id>.blend`，并导出 `public/assets/jets/<id>/{showcase,game}.glb`；展示级约 10–12 万三角面、任务级约 0.7–1 万三角面，Draco 压缩。`src/data/jet-models.json` 记录尺寸、预算、喷口/灯位锚点和材质。
- **游戏加载**：`render/jet-assets.ts` 用 GLTFLoader + DRACOLoader 预载任务低模；机库按需异步加载展示级模型并原地替换；失败或 `?jets=procedural` 时回退到 `render/girl-jets.ts` 的程序化 Blueprint 模型。
- **涂装**：材质分色 + 几何云纹/金线/编号贴花；青鸾玉白/青瓷绿/淡金，明璃漆白/朱红/深蓝，苍穹午夜蓝/青蓝 EW 灯带，星隼石墨灰/钴蓝/电蓝，霜翼霜白/钢蓝/冷青。
- **设计对照**：机库保留展示 / 俯视 / 侧视 / 正视四机位，用来对照三视图轮廓和比例。
- **取舍**：这是设计图级重建，不是 CAD/照片级；实时 GLB 暂不含面板缝几何，避免细管在浏览器里采样成虚线；密集缝线保留在 `.blend` / Cycles 渲染中。

### 9.2 爆炸 / 震动 / 音效

- 爆炸池：核心闪光精灵、低模火球、火粒子/烟粒子、金属碎片 InstancedMesh、火星 InstancedMesh、冲击波环、炮口闪光；区分空中/地面/水面，Boss 死亡多波连环爆。
- 震动：`render/camera-shake.ts` 的 trauma 系统，trauma² 映射到 X/Z 位移、屏幕 roll、正交 zoom；击杀/受击/Boss/特技按级别触发，平滑衰减并在暂停/结算归零；保留设置里的震动开关。
- 音频：`playExplosion(scale, pan, surface)` 四层合成（低频下潜、噪声主体、裂响、延迟碎片）+ StereoPanner 声像；`playImpact` 金属/护盾；`startEngine/setEngine/stopEngine` 关卡引擎底噪；压缩器与单帧限流防止削波。

## 10. 技术架构

```
App（屏幕状态机 + SaveService/AudioEngine/InputService/Viewport）
 ├─ render/Viewport          WebGL + EffectComposer + 后处理
 ├─ render/WorldEnvironment  天空、太阳、顶光、云、雾、阴影
 ├─ render/City              程序化城市/港湾 + 碰撞体 + 地面刷点
 ├─ data/jet-blueprints     五机娘三视图站位/翼面/喷口/编号（程序化回退基准）
 ├─ data/jet-models         Blender 资产 manifest（路径/预算/锚点）
 ├─ render/jet-assets       GLTFLoader + DRACOLoader、GLB → JetVisual、异步/回退
 ├─ render/girl-jets        Blender 资产优先 + 程序化 Blueprint 回退
 ├─ render/camera-shake      trauma² 相机震动（位移/roll/zoom）
 ├─ game/effects            闪光/火球/火/烟/碎片/火星/冲击波/炮口/尾迹池
 ├─ game/shmup/
 │   ├─ player               八方向移动/过热/导弹/特技/重生
 │   ├─ enemy                空中编队 + 地面滚动单位
 │   ├─ boss                 铁颚/潮汐/烛龙/天枢四种模型与弹幕
 │   ├─ bullets              玩家/敌机双向弹幕池
 │   ├─ runner               卷轴/波次/目标/碰撞/评分/结算
 │   └─ types                屏幕坐标目标与 HUD 快照
 ├─ ui/shmup-hud             分数/连击/目标/卷轴/判定点/Boss 条
 └─ app/screens             标题/母舰/简报/机库/档案/剧情/关卡/结算/设置/结局
```

- 模拟固定 1/60 步进（调试推进可复现），渲染跟随真实帧。
- 关卡使用屏幕坐标：玩家/空中敌机/子弹为 `zRel`，地面单位用世界 Z 换算，镜头滚动只影响背景与地面目标。
- 内容数据集中在 `src/data/`，任务/剧情/机娘均为数据驱动。
- 素材管线：`scripts/prepare-art.mjs` 用 ffmpeg 从概念图裁切/转码 WebP，生成 `art-manifest.json`；`scripts/build-jets.mjs` 调用 Blender 生成 `.blend`/GLB/manifest，`scripts/validate-jets.mjs` 做结构/预算校验。

## 11. 当前状态与边界

已完成：完整流程、四关、四关关底 Boss（铁颚/潮汐/烛龙/天枢）、五机娘、剧情/结局、存档、升级、信赖、设置、档案、竖版 HUD、五台 Blender 重建战机（showcase/game GLB + Draco + 程序化回退）、设计对照、场景细节、分层爆炸、trauma 震动、分层音效、截图与测试。

未做/取舍：M1–M3 的 Boss 专属机制/弹幕仍可深化（目前共用部分骨架）；关卡内火力/炸弹道具掉落、3D 机娘人形、真人语音、移动端、联机；五台机是设计图级重建而非 CAD 级，实时 GLB 暂不含面板缝；爆炸仍是风格化低模；数值为首轮平衡。
